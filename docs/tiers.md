# The three enrichment tiers

How much realism you get out of a persona depends entirely on how much
public-source material you've fed it. The tiers degrade gracefully — Tier 3
falls back to Tier 2 falls back to Tier 1.

## ★1 — Profile (required, 5 min per persona)

The minimum to make a persona work:

- `persona.json` — slug, company, role, HQ, size, zone, what they do, default macOS voice
- `personality.md` — 2-3 sentence internal state (skeptical? polished? procurement-driven?)
- `speech_profile.md` — linguistic fingerprint (region, sentence length, words they'd never use)
- `pushbacks.txt` — verbatim objections, one per line

**What you get:** the model plays the role consistently. The voice is one of
the macOS built-in voices. Generic but credible — better than ChatGPT
roleplaying "an enterprise buyer."

## ★2 — Quotes + transcripts (5-30 min per persona)

For people with public footprints (CEOs, founders, conference speakers):

- `examples.md` — verbatim quotes from public talks, podcasts, interviews. Format:
  ```
  ## (source: WSJ profile · 2017)
  > Real quote here.
  ```
- `transcripts/*.txt` — full transcripts of public appearances. Generated by:
  ```bash
  python3 personas/manage.py ingest-talk <slug> <youtube-url-or-file>
  ```
  This downloads the audio via `yt-dlp`, transcribes with `whisper.cpp`, and
  drops the transcript in `transcripts/`.

The first 2000 chars of each transcript are included in the system prompt.
The model picks up cadence, diction, characteristic phrases.

**What you get:** the persona starts saying things in the actual person's
voice. Test it — feed Bill Hinshaw's WSJ interview transcript into his
persona and watch the model start using "son" and "pal."

## ★3 — Cloned voice (10 min + one-time install)

For when you want the AI to actually *sound* like the person on the phone:

1. Get a 30+ second clip of the real voice (public talk, podcast)
2. Save it as `personas/<slug>/voice/sample.wav`
3. One-time install: `pip install "TTS>=0.22.0"` (~3GB total deps + model)
4. Clone: `python3 personas/manage.py clone-voice <slug>`

The training server uses XTTS-v2 to synthesize replies in the cloned voice.

### Ethical note

Voice cloning a real person without consent is sketchy territory. The whole
purpose of Tier 3 is **internal rehearsal** — your AI roleplay partner sounds
like the real buyer so you practice better.

Do NOT use cloned voices for any external output (recordings, marketing,
deepfake content). The training server hard-locks audio output to in-browser
playback — there's no download path by design.

If the person you're cloning is genuinely public-figure-level (CEO, politician,
historical figure), the ethical floor is lower. If they're a private VP at a
private company, think carefully before you clone. The Tier 1 macOS voice may
be enough.

## Visibility into which tier a persona is at

```bash
python3 personas/manage.py list
```

Output looks like:
```
TIER   SLUG               COMPANY              ZONE              ENRICHMENT
★★·    cobol-cowboys      Cobol Cowboys        Boutique Partner  5q
★··    rocket-software    Rocket Software      Tool Partner      —
★★★    bill-hinshaw       Cobol Cowboys        Boutique Partner  5q, 2t, voice-cloned
```

`q` = verbatim quotes loaded · `t` = transcripts · `voice-cloned` = Tier 3 active.
