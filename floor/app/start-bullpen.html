🛠 Set up the other device first

On the device that will host the bullpen, run:

git clone https://github.com/SipMyBeers/bullpenlm.git
cd bullpenlm
python3 server/server.py
# then open localhost:7878/app/start-bullpen.html on that machine

Come back to that wizard and pick This device. Closes this tab is fine — your progress here isn't saved anyway.
